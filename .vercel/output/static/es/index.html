La app es de uso exclusivo para pacientes de la clínica.

App móvil de pacientes para una clínica en España, publicada en Google Play. Desarrollé el frontend con React y Capacitor, junto a un desarrollador backend.

Qué hice

  • El frontend completo de la app de pacientes, en React con Capacitor, para Android e iOS desde un mismo código.
  • La integración con la API y la autenticación del backend (Supabase Auth), y las notificaciones push con Firebase Cloud Messaging.
  • La ficha de Google Play (textos y recursos gráficos) para la publicación.

Cómo trabajamos

  • Yo me ocupé del frontend, y otro desarrollador del backend y de la publicación en iOS.
  • Una rama por feature desde dev, con Pull Requests antes de llegar a main.
  • Antes de programar cada feature, escribíamos un análisis, un overview y un plan.
  • Documentos en lenguaje simple para el cliente, que no es técnico.
