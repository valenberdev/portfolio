View on Google Play ↗

The app is only for the clinic's patients.

A mobile patient app for a clinic in Spain, published on Google Play. I built the frontend with React and Capacitor, alongside a backend developer.

What I did

  • The whole frontend of the patient app, in React with Capacitor, for Android and iOS from a single codebase.
  • The integration with the backend’s API and authentication (Supabase Auth), and push notifications with Firebase Cloud Messaging.
  • The Google Play listing (copy and graphics) for the release.

How we worked

  • I owned the frontend, and another developer owned the backend and the iOS release.
  • One branch per feature off dev, with Pull Requests before anything reached main.
  • Before coding each feature, we wrote an analysis, an overview and a plan.
  • Plain-language documents for the client, who isn’t technical.
